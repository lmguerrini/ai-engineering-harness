# RP2.3 — failure-mode closure matrix

**The rule this table exists to enforce:** a proposed *solution* may be deferred;
a verified *failure mechanism* may not remain able to recur. Every mechanism
below is either **PREVENTED** (it cannot be expressed), **DETECTED_AND_BLOCKED**
(it is caught and stops the work), **SAFELY_RECOVERABLE** (it can happen and
costs bounded, recoverable work), **ALREADY_COVERED** (an existing guarantee
closes it, **and the discriminating oracle that would go red is named**), or
**DEFERRED** (recurrence cannot violate an RP2.3 guarantee or recreate a
verified failure).

`ALREADY_COVERED` was spelled `COVERED` until the final evidence-closure check,
and the rename is not cosmetic: six rows carried it, and **two of them named no
oracle at all** — one said only *inherited from 2.2.0; no new evidence in this
phase*, which is a description of inheritance and not a demonstration. That row
is `DEFERRED` now, with the reason written out. Coverage claimed without an
oracle is the assertion this matrix exists to refuse, made by the matrix.

A deferral appears here only where the *mechanism* has a disposition and the
deferred item is an improvement on top of it. Where that is the case, the
deferred item and its trigger are named.

**Every row names the oracle that would go red if its mechanism reopened, and
every one of them was executed.** That was added by the final
evidence-completeness audit, which found that 51 of 69 rows described their
closure in prose and named nothing runnable — a description of a mechanism is
evidence about the design, not a demonstration that it holds today, and the
difference is the whole discipline of this release applied to its own matrix.
Four of the selectors written first matched no test at all and reported green by
selecting nothing; they are corrected, and the run counts each row's tests for
exactly that reason.

Every row's evidence is a test or a rehearsal in this release, or a named
guarantee in a prior qualified one. Nothing here is closed by prose.
